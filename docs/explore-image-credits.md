## Lưu trữ

Ảnh nằm trên Cloudinary, thư mục `vietverse/lesson-images/explore/`. Bảng ánh xạ chữ → URL ở `server/src/seeds/customer/exploreCurriculumImages.ts` (khoá `B<bài>:<chữ>` ưu tiên hơn khoá chung).
